Protocol

how I ship with agents
P1

Discover in the field

Sit with the people who own the workflow. Map what actually happens — not the org chart's version. Use cases tied to measurable value, or they don't get built.

P2

Spec before code

Decision-complete specs and architecture decision records. Dantra shipped against 8 ADRs and a risk-ranked test strategy — agents build fast; direction is the scarce input.

P3

Agents build, gates decide

Multi-agent Claude Code workflows: planner, builder, reviewer, red-team. The red-team agent has a veto. AI output is a draft until it passes evaluation.

P4

Evals are the product

Cross-tenant isolation matrix on every merge, no override. Concurrency-stressed money math. Adversarial security review before launch. That's why the finding count is zero.
